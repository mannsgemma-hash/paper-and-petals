B Install in four steps

  1. Copy the files inDrag Scripts/UI into Assets/Scripts/UI and Sprites anywhere under Assets/. Unity compiles the scripts automatically. You need TextMeshPro installed (Window ▸ TextMeshPro ▸ Import TMP Essentials).
  2. Create the themeRun Tools ▸ Paper & Petals ▸ Create Theme Asset. This writes Assets/Resources/PaperPetalsTheme.asset with all brand colors pre-filled. Because it lives in Resources and is named exactly PaperPetalsTheme, every component auto-loads it — no manual wiring.
  3. Prep the spritesRun Tools ▸ Paper & Petals ▸ Apply Sprite Import Settings. It sets each pp_*.png to Sprite, 400 px-per-unit, and the correct 9-slice border. Then drag them onto the matching fields of the theme asset.
  4. Bake & assign fontsCreate TMP Font Assets from the four recommended families (next section) and drop them on the theme's font slots. Done — drop any component onto a Canvas and it styles itself.
Reference canvas. The whole system is specced at 1024 × 768 (iPad landscape). Set your Canvas Scaler to Scale With Screen Size, reference resolution 1024 × 768, match 0.5. All px values below assume that.

Making a TMP Font Asset

  1. Download the .ttfGrab the families from fonts.google.com (all four are OFL). Import the .ttf files into Assets/Fonts/….
  2. Generate SDFWindow ▸ TextMeshPro ▸ Font Asset Creator. Source font = the imported .ttf, Render Mode = SDFAA, Atlas 1024², Character Set = Extended ASCII (or your locale). Generate, then Save the asset next to the font.
  3. Assign to the themeDrop each Font Asset onto displayFont / uiFont / scriptFont / flourishFont. Components pull from these automatically.
Letter-spacing. CSS tracking is em-based; TMP's characterSpacing is roughly em × 100. The label tracking .16em → 16, micro badges .20–.22em → 20–22. These are stored on the theme (lsLabel, lsMicro).

E The 9-slice sprites

uGUI has no border-radius or box-shadow — rounded surfaces are sliced sprites. These are white & tintable: one fill + one matching ring per radius, plus a soft shadow. Tint them from the theme; swap for hand-painted paper textures whenever you like (keep the same border).

pp_fill_r6buttons · inputs · border 24
pp_fill_r10palette · trays · border 40
pp_fill_r16cards · panels · border 64
pp_fill_pillbadges · chips · border 64
pp_stroke_r16ring · tint = hairline
pp_shadow_r16soft paper shadow
Import settings (the menu applies these): Texture Type Sprite (2D & UI), Mesh Type Full Rect, Pixels Per Unit = 400 (baked at 4× so corners land at the css radius on a 100-PPU canvas), 9-slice Border = the value above, Filter Bilinear, Wrap Clamp, mipmaps off, Alpha Is Transparency on. On the Image component set Image Type = Sliced.

F Building each component

Each script auto-styles from the theme in edit mode ([ExecuteAlways] / OnValidate), so you build the hierarchy once, wire the graphics, and it looks right immediately. green = the GameObject carrying the script; orange = the field you assign it to.

Button — PPButton

Derives from uGUI Button, so you keep onClick, navigation and interactable. Set variant (Primary / Secondary / Ghost / Danger) and pill. Primary fills forest with cream text; secondary & danger show the stroke ring.

Button Image = pp_fill_r6 (or pp_fill_pill) · PPButton · ContentSizeFitter opt. ├─ Stroke Image = pp_stroke_r6 → field stroke (secondary/danger) └─ Label TextMeshProUGUI → field label

Rarity badge — PPBadge & filter chip — PPChip

Both are pills. PPBadge is static and maps Common / Uncommon / Rare / Heirloom to the rarity colors. PPChip toggles on click (with the hover-lift feel) and fires onValueChanged.

Badge / Chip Image = pp_fill_pill → field fill ├─ Stroke Image = pp_stroke_pill → field stroke ├─ Dot Image = pp_fill_circle → field dot (chip only, optional) └─ Label TextMeshProUGUI → field label

Card — PPCard

Cream surface, parchment hairline, layered paper shadow. Toggle stitched to hide the border and show the inset hand-stitch ring instead.

Card PPCard ├─ Shadow Image = pp_shadow_r16 → field shadow (slightly larger, behind) ├─ Fill Image = pp_fill_r16 → field fill ├─ Border Image = pp_stroke_r16 → field border ├─ Stitch Image = pp_stroke_r16 → field stitch (optional, inset ~6px) └─ (your content)

Input field — PPInputField

Wraps a TMP_InputField. Cream surface + hairline; on focus the border turns sage and a soft sage ring appears — never blue.

Field TMP_InputField · PPInputField ├─ FocusRing Image = pp_stroke_r6 → field focusRing (off until focus) ├─ Border Image = pp_stroke_r6 → field border ├─ Background Image = pp_fill_r6 → field background └─ Text Area ▸ Text / Placeholder → fields textComponent / placeholder

Navigation rail — PPNavItem + PPNavGroup

Put PPNavGroup on the rail; it finds the child items and enforces single-selection. Active item fills forest with cream icon + label; inactive warms on hover. Icons are outline sprites (Tabler-style, 1.75px stroke) tinted by the script.

Rail PPNavGroup (VerticalLayoutGroup) ├─ NavItem Image = pp_fill_r10 · PPNavItem │ ├─ Icon Image = outline sprite → field icon │ └─ Label TextMeshProUGUI → field label └─ … more NavItems
Icons. The system uses Tabler outline icons (outline only, 1.75px stroke, rounded caps). Export the SVGs you need from tabler-icons.io, import as Sprites, and tint via the NavItem — don't fill them.

G The paper-physics feel

Soft, slow, weighted — never bouncy. The motion is baked into the components; these are the values, stored on the theme so you can tune globally.

GestureWhat happensDuration · easing
Hover (mouse)element lifts hoverLift = 2px, background warms one step240 ms · easePaper
Press (touch)scales to pressScale = 0.96, sinks back to base Y150 ms · easePress

// CubicBezier matches the CSS curve exactly (Newton-Raphson solve).
var ease = CubicBezier.Paper;          // cubic-bezier(0.32,0.72,0.32,1)
float k = ease.Evaluate(t01);            // eased 0..1 for your own tweens

// Reduced motion? Pass duration 0 and the tween snaps instantly.
StartCoroutine(PPMotion.LiftPress(rt, baseY, baseY + 2f, 0.96f, dur, ease));
No bounces, no overshoot, no elastic. The settle curve lands paper with weight by slowing in the last 20% instead of springing past the target.
